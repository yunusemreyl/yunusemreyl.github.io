Engineering student based in Turkey, specialising in Linux systems, embedded hardware, and robotics. I started OMEN Command Center for Linux because my HP Victus had no proper Linux support — fan control, GPU switching, and RGB were all broken. So I fixed them myself, from the kernel driver up to the GTK4 UI.

When I'm not debugging ACPI tables I'm playing CS2, studying kernel internals, or planning the next open-source tool nobody asked for but everyone needs.
